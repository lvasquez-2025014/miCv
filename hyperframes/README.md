# Proyecto HyperFrames — Silueta Épica

Este proyecto sigue la estructura de **HyperFrames** (`index.html` + `compositions/hero-scene.html` + `assets/hero.jpg`).

## Cómo abrir o renderizar con HyperFrames

1. Instala o ejecuta HyperFrames CLI (requiere Node.js y FFmpeg):
   ```bash
   npx hyperframes check
   npx hyperframes preview
   npx hyperframes render --output hero_hyperframes.mp4
   ```
2. También puedes abrir esta carpeta directamente en **HyperFrames Studio**.
